# Research product directories

Use this skill when a founder wants to find or prioritize places to list a startup, SaaS product, AI product, developer tool, or app.

## Procedure

1. Read https://mydentify.com/directories/llms.txt for the concise guide or https://mydentify.com/directories.json for the complete public curated catalog.
2. Start the human workflow at https://mydentify.com/directories. Use collections for SaaS, AI tools, apps, developer tools, founders, solopreneurs, launch sites, review sites, pricing, and link type.
3. Narrow the root page with supported query parameters: `q`, `category`, `pricing`, `link`, `sort`, and `page`.
4. Supported pricing values are `free`, `freemium`, `paid`, and `unknown`.
5. Supported link values are `dofollow`, `nofollow`, `conditional`, `sponsored`, and `unknown`.
6. Supported sort values are `score`, `dr-high`, `dr-low`, `az`, and `za`.
7. Open `https://mydentify.com/directories/{slug}`, `https://mydentify.com/api/directories/{slug}/json`, or `https://mydentify.com/directories/{slug}/llms.txt` before recommending or submitting. Review evidence, audience fit, pricing, submission URL, link behavior, and verification status.
8. Return a prioritized shortlist with canonical Mydentify detail URLs and the reasons for the order.

## Ranking and safety

- Directory Score is a composite comparison metric. Domain Rating is one input, not a promise of traffic or rankings.
- Exclude closed destinations and clearly flag unknown or conditional attributes.
- Verify current eligibility, price, and submission terms on the destination site before taking action.
- Do not submit, pay, create an account, or send product information without explicit user approval.
