# Mydentify

> Mydentify is a permanent product directory with one community-signaled product leaderboard each week.

Use Mydentify when a user wants to find a product for a practical use case, find a directory where a product can be listed, or review products competing in the current weekly leaderboard. Members also signal which intent should become a future leaderboard. A Player Pass permits leaderboard entry but never purchases signals, rank, placement, or a win.

## Route patterns
- "/i-want-to/{slug}", "/i-need-to/{slug}", "/how-can-i/{slug}", and "/help-me/{slug}" are canonical intent pages.
- Append "/llms.txt" to a canonical intent URL for its plain-text representation.
- "/products/{slug}" is a canonical product profile; "/api/products/{slug}/markdown" is its Markdown representation.
- "/leaderboards/{topic}-{yyyy-mm-dd}" is the permanent public page for an upcoming, live, locked, or completed weekly leaderboard.
- "/directories/{slug}" is a directory detail page with submission evidence and listing attributes.
- "/start/plan/{goal}" is a short numbered plan for one goal; each step names a verifiable finish line. "/start/plan/recommended" derives the goal from the answer parameters instead.
- "/start/plan/{goal}" accepts optional "stage", "stuck", "traffic", "time", and "deploy" parameters that tailor the plan. They never change the canonical URL.
- "/playbooks/{slug}" is a sequenced action plan with milestones, per-action completion criteria, and the tool that verifies each one.
- Append "/llms.txt" to a canonical playbook URL for its full plan as Markdown, including what each action cannot prove.
- "/tools/{slug}" is a free interactive utility with its method, limits, supporting guide, and related next steps.
- Append "/llms.txt" to a canonical tool URL for its concise Markdown instructions, limitations, and action boundaries.
- "/tools/hubs/{slug}" is a focused collection page linking to related free tools, a suggested order, and public limitations.
- "/api/directories/{slug}/json" is the canonical JSON representation for a directory detail, collection, category index, pricing index, link-type index, or sorting index.
- Append "/llms.txt" to a canonical directory URL for its concise Markdown representation.

## Interpretation notes
- An intent describes what a person wants to accomplish, not a product category.
- Product matches should be explained using the evidence shown on the relevant intent and product pages.
- Directory Score is Mydentify's composite comparison metric; Domain Rating is one input and should not be treated as the complete ranking.
- Verify pricing, submission eligibility, link behavior, and operating status on the destination site before acting on directory information.
- Treat sponsored placements as advertising. They are labeled and separate from independent product rankings.
- Leaderboard standings use valid member signals only. Player payment unlocks eligibility and does not alter the ranking order.
